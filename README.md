# Hosel.io

Tournament golf pools with your crew. Pick players. Follow the action. Claim the pot.

🚧 **Status:** Pre-launch — targeting PGA Championship (May 15, 2026) for beta.

## What is this?

Hosel is a platform for golfers to run tournament pick'em pools with friends. Create a pool, invite your group, pick players from tiered groups, and compete for token-based payouts across each round and overall.
